4. ผลงานวิชาการ

คู่มือปฏิบัติงาน

คู่มือการปฏิบัติงานการจัดการศึกษาและการบริหารหลักสูตร

เพื่อใช้เป็นมาตรฐานในการปฏิบัติงานสนับสนุนวิชาการของสถาบันฯ ให้มีความถูกต้องและรวดเร็ว

รายงาน

รายงานการประเมินคุณภาพการศึกษาภายใน (SAR) ระดับหลักสูตร

รวบรวมข้อมูลและจัดทำรายงานผลการดำเนินงานของหลักสูตรเพื่อรับการประเมินคุณภาพประจำปีการศึกษา

โครงการ

โครงการพัฒนาระบบสารสนเทศเพื่อการบริหารจัดการข้อมูลนักศึกษา

ร่วมวิเคราะห์ระบบและประสานงานกับทีมพัฒนาเพื่อสร้างระบบฐานข้อมูลที่ตอบโจทย์ผู้ใช้งานจริง

บทวิเคราะห์

บทวิเคราะห์สถิติผู้รับบริการคลินิกพิเศษ

จัดทำรายงานวิเคราะห์เชิงสถิติเพื่อนำเสนอต่อผู้บริหารในการวางแผนอัตรากำลังและช่วงเวลาให้บริการ

5. ผลงานบทความวิจัย

ผลงานการค้นคว้าและวิจัยเพื่อพัฒนาการทำงานและองค์ความรู้ทางวิชาการ

การบริหารการศึกษา 2568 (กำลังดำเนินการ)

ปัจจัยที่มีผลต่อประสิทธิภาพการทำงานของบุคลากรสายสนับสนุนในสถาบันอุดมศึกษา

การวิจัยเชิงสำรวจเพื่อศึกษาปัจจัยเชิงสภาพแวดล้อมและแรงจูงใจที่ส่งผลต่อการปฏิบัติงาน โดยเน้นการประยุกต์ใช้ในการบริหารทรัพยากรมนุษย์ (ส่วนหนึ่งของการศึกษา ป.โท)

ผู้แต่ง: นุสรา สุปัน

เศรษฐศาสตร์/ธุรกิจ 2562

พฤติกรรมการตัดสินใจเลือกซื้อสินค้าออนไลน์ของกลุ่มนักศึกษาในเขตกรุงเทพมหานคร

การศึกษาเชิงปริมาณเพื่อวิเคราะห์ปัจจัยทางเศรษฐศาสตร์ที่มีผลต่อพฤติกรรมผู้บริโภคในยุคดิจิทัล (สารนิพนธ์ ป.ตรี)
